# Учебный frontend-проект

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт учебного интернет-магазина.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров со статическими фильтрами;
- `product.html` — описание товара, изображение, цена и таблица характеристик;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация и ссылка на форму заявки;
- `css/style.css` — общий файл стилей;
- `js/main.js` — открытие и закрытие модального окна, проверка формы;
- `images/product.svg` — учебное изображение товара;
- `.gitignore` — список файлов, исключённых из Git;
- `README.md` — описание проекта.

## Используемые технологии

- CSS;

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

Сайт состоит из пяти связанных страниц. На всех страницах используется общее меню и внешний CSS-файл. На внутренних страницах есть хлебные крошки.

На главной странице размещены преимущества и популярные товары. В каталоге есть карточки товаров и статические фильтры. На странице товара показаны изображение, описание, цена и таблица характеристик. Оставить заявку можно на отдельной странице или в модальном окне на главной.

Форма проверяет обязательные поля, e-mail и формат телефона. После успешной проверки появляется сообщение «Форма успешно отправлена!». Данные на сервер пока не отправляются.

В стилях используются CSS-переменные, состояния `:hover` и `:focus-visible`, Flexbox для меню и Grid для карточек и каталога. Классы оформлены по БЭМ. Карточка имеет `position: relative`, бейдж «Хит» — `position: absolute`. Боковой фильтр использует `position: sticky` и `z-index`.

## Как открыть проект

Откройте `index.html` в браузере или запустите проект через расширение Live Server в VS Code. Также можно открыть опубликованную версию по ссылке ниже.

Для проверки перейдите по всем пунктам меню, откройте товар из каталога и страницу заявки. Попробуйте отправить пустую форму, затем заполните обязательные поля правильно. На главной странице проверьте кнопки «Заказать» и модальное окно.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `product-details` — описание товара;
- `product-table` — таблица характеристик;
- `order-page` — страница заявки;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал сайта.
